# Nexus AI Technology Website

A modern, dark-themed AI company website built with HTML and CSS.

## Files
- `index.html` — Main HTML structure
- `style.css` — All styling and responsive design

## How to view
1. Download this repository
2. Open `index.html` in any browser (Chrome, Edge, Firefox)

## Features
- Responsive design (works on mobile and desktop)
- Hero section with stats
- AI Products, Technology features, Team, Contact form
- Modern dark theme

## Deploy
You can deploy this easily using GitHub Pages.
